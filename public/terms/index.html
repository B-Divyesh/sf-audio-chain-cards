What this tool does

Chain Cards records and shares audio-processing procedures. It can format FFmpeg commands for review and copying. It does not run those commands, process audio, supply proprietary restoration models, or guarantee that a procedure will improve a recording.

Your responsibility

Processing changes audio. Keep the original, inspect every command, use a distinct output path, confirm that you are allowed to process the recording, and audition each result. Tool names and example settings are educational starting points, not professional engineering advice.
